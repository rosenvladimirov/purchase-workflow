Purchase Order Secondary Unit with Editable Factor

Enhance your purchase orders with flexible secondary units of measure!

This module extends the standard Odoo purchase order functionality to allow using secondary units of measure with editable conversion factors directly in purchase order lines.

Key Features

✏️ Editable Conversion Factor

Unlike similar modules where the conversion factor is fixed, this module allows you to edit the conversion factor directly in each purchase order line.

🔄 Automatic Calculations

Enter quantity in either primary or secondary units - the other is calculated automatically using the formula: Primary Qty = Secondary Qty × Factor

📦 Flexible Packaging

Handle special purchase situations where conversion may differ from the standard (e.g., special packaging, promotional offers) without creating new products.

🔗 Stock Integration

Secondary unit information is seamlessly transferred to stock moves for complete traceability.

Use Case Examples

Example 1: Standard Conversion

Product: Screws

  • Primary UoM: Units (pcs)
  • Secondary UoM: Box
  • Standard factor: 1 Box = 100 Units

In Purchase Order:

  • Secondary Qty: 5 Boxes
  • Factor: 100 (default from product)
  • Primary Qty: 500 Units (automatically calculated)

Example 2: Special Purchase Case

Product: Screws (same as above)

Supplier offers special mega-box:

  • Secondary Qty: 2 Mega-Boxes
  • Factor: 500 (manually edited!)
  • Primary Qty: 1000 Units (automatically calculated)

This flexibility allows handling special packaging without creating new products!

How It Works

  1. Install the module
  2. Configure secondary units on your products (requires product_secondary_unit)
  3. Create a purchase order and select a product
  4. Choose the secondary unit from the dropdown
  5. Edit the conversion factor if needed
  6. Enter quantity in either field - the other calculates automatically
