This module extends the standard Odoo purchase order functionality to allow using 
secondary units of measure with **editable conversion factors** directly in purchase order lines.

Unlike similar modules where the conversion factor is fixed and taken only from the 
product configuration, this module allows you to:

* **Edit the conversion factor** directly in each purchase order line
* Override the default factor from the product if needed
* Handle special purchase situations where conversion may differ (e.g., special packaging)

Features
========

* Add secondary unit of measure to purchase order lines
* **Editable conversion factor** for each line (key difference from standard modules)
* Automatic calculation of primary quantity when entering secondary quantity
* Automatic calculation of secondary quantity when entering primary quantity
* Default factor loaded from product but can be overridden per line
* Seamless integration with stock moves
* Compatible with standard Odoo purchase workflow

Use Cases
=========

Example 1: Standard Conversion
-------------------------------
Product: Screws
- Primary UoM: Units (pcs)
- Secondary UoM: Box
- Standard factor: 1 Box = 100 Units

In Purchase Order:
- Secondary Qty: 5 Boxes
- Factor: 100 (default from product)
- **Primary Qty: 500 Units** (automatically calculated)

Example 2: Special Purchase Case
---------------------------------
Product: Screws (same as above)
- Standard factor: 1 Box = 100 Units

Supplier offers special mega-box:
- Secondary Qty: 2 Mega-Boxes
- **Factor: 500** (manually edited)
- Primary Qty: 1000 Units (automatically calculated)

This flexibility allows handling special packaging without creating new products.

Configuration
=============

1. Install the module
2. Go to Products and ensure you have secondary units configured (requires product_secondary_unit module)
3. Define default conversion factors on products

Usage
=====

Creating a Purchase Order with Secondary Units
-----------------------------------------------

1. Go to Purchase > Orders > Purchase Orders
2. Create a new purchase order
3. Add a product line
4. Select the secondary unit of measure
5. **Edit the conversion factor if needed** (this is the key feature!)
6. Enter quantity in either:
   - Secondary Qty field (primary qty will auto-calculate)
   - Primary Qty field (secondary qty will auto-calculate)

The conversion formula is:
    **Primary Qty = Secondary Qty × Factor**

Editing the Conversion Factor
------------------------------

In the purchase order line:
- The "Conversion Factor" field is visible when a secondary unit is selected
- Click on the factor field and enter the desired value
- The quantities will automatically recalculate
